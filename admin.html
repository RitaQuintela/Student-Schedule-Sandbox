Excel template & rules

Excel template

A blank file with the right columns and a few example rows, including how to pair T and PL sections with the Annotations column.

Rules the app follows
  • One row = one weekly class. Rows are grouped into courses by ModuleCode, and into sections by SectionName. A section can have several rows (several classes a week).
  • Week lists the Mondays of the weeks the class happens, separated by commas. The real date is that Monday plus the weekday. Missing weeks (holidays) simply aren't listed.
  • T/PL pairing is set in the Annotations column of the T rows, e.g. “For PL-G1, PL-G2 and PL-E1.” A PL not mentioned in any note goes with the T section(s) that have no pairing note. Students pick a PL; its T comes with it.
  • If a course has PL sections but no T, its TP sections play the role of the T.
  • If several T sections have no pairing note, PLs are matched by number (PL1-A → T1) and you get a warning, so add notes to make it official.
  • Courses without PL sections (TP, O, S) offer one choice per section.
  • Any other Annotations text (e.g. “Online course…”) is shown to students.
  • Classes should be Monday–Friday between 08:00 and 20:00.
  • Exams come from the planner's ExamData sheet (Master rows). They are linked to courses by name, ignoring small differences (& / and, hyphens, accents, text in brackets, a final “s”). “Language Courses” covers every language course. Names that still don't match are listed as warnings.
  • Two exams on the same day are a clash (red). Exams on consecutive days get an amber note.
